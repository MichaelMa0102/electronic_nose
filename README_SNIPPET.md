## Latest experiment

### Orange Peel Trial 002

A second independent orange-peel exposure produced a strong reversible response:
- stable baseline: **411.5 kOhm**
- minimum exposure resistance: **160.2 kOhm**
- normalized drop: **61.1%**
- baseline CV: **0.270%**

The same trial also showed a **4.90 percentage-point humidity increase**, so humidity remains an important confound. See `experiments/003_orange_002.md`.
