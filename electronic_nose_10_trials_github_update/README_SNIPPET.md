## Latest dataset milestone

### Orange Peel — 10 Independent Trials

The project now has ten independent orange-peel trials (`orange_001` through `orange_010`).

Across the current summary:
- median gas-resistance drop during recorded exposure: **65.6%**
- observed drop range: **47.9%–94.5%**
- humidity increase range: **2.1–30.7 percentage points**

The response is clearly repeatable relative to short-term baseline noise, but this does **not** yet prove orange-specific recognition. Humidity, airflow, peel age, distance, and motion remain important confounds.

Next dataset target: **10 clean-air / sham-exposure trials** using the same timing and physical procedure.

See `experiments/012_orange_10_trial_summary.md`.
