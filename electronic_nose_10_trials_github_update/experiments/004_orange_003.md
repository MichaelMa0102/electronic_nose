# Orange Peel Trial 003

## Purpose

Independent orange-peel response trial for the ESP32-S3 + BME688 electronic-nose prototype.

## Hardware and logger

- ESP32-S3-N16R8
- BME688 breakout at I2C address `0x77`
- SDA: GPIO 8
- SCL: GPIO 9
- Supply: 3.3 V
- Gas heater: 320 C for 150 ms
- Serial baud: 115200

## Event timing

- Baseline: `< 300,000 ms`
- Orange-peel exposure: `300,000–400,000 ms`
- Recovery: `> 400,000 ms`

The event boundaries come from the experimenter's manual record.

## Files

- Raw sensor data: `data/raw/orange_003.csv`
- Labeled data: `data/processed/orange_003_labeled.csv`
- Quantitative summary: `data/processed/orange_003_summary.csv`

## Quantitative results

- Samples stored: **180**
- Stable/available baseline gas resistance: **300.6 kOhm**
- Baseline gas CV: **0.417%**
- Minimum exposure gas resistance: **16.6 kOhm** at **315.2 s**
- Maximum decrease from baseline: **94.5%**
- Baseline humidity: **65.14% RH**
- Peak exposure humidity: **67.32% RH**
- Humidity increase: **2.19 percentage points**
- Final-60-s recovery gas mean: **216.2 kOhm**
- Approximate recovery fraction: **70.3%**

## Data-quality note

Only the segment beginning at 276,907 ms was supplied, so the available pre-exposure baseline is about 23.1 seconds. No earlier samples were invented or reconstructed.

## Interpretation

The trial shows a large response relative to short-term baseline noise, but the BME688 is cross-sensitive and humidity changed during exposure. This run is evidence of repeatable sensor response, not proof that the signal is orange-specific.

## Next use

Keep this trial as one independent unit. For machine-learning evaluation, split by whole trial rather than randomly splitting individual time samples.
