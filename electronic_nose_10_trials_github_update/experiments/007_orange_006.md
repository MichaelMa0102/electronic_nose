# Orange Peel Trial 006

## Purpose

Independent orange-peel response trial for the ESP32-S3 + BME688 electronic-nose prototype.

## Hardware and logger

- ESP32-S3-N16R8
- BME688 breakout at I2C address `0x77`
- SDA: GPIO 8
- SCL: GPIO 9
- Supply: 3.3 V
- Gas heater: 320 C for 150 ms
- Serial baud: 115200

## Event timing

- Baseline: `< 100,000 ms`
- Orange-peel exposure: `100,000–200,000 ms`
- Recovery: `> 200,000 ms`

The event boundaries come from the experimenter's manual record.

## Files

- Raw sensor data: `data/raw/orange_006.csv`
- Labeled data: `data/processed/orange_006_labeled.csv`
- Quantitative summary: `data/processed/orange_006_summary.csv`

## Quantitative results

- Samples stored: **221**
- Stable/available baseline gas resistance: **342.8 kOhm**
- Baseline gas CV: **0.748%**
- Minimum exposure gas resistance: **58.6 kOhm** at **127.7 s**
- Maximum decrease from baseline: **82.9%**
- Baseline humidity: **47.80% RH**
- Peak exposure humidity: **54.62% RH**
- Humidity increase: **6.82 percentage points**
- Final-60-s recovery gas mean: **299.3 kOhm**
- Approximate recovery fraction: **84.7%**

## Environment note

The air conditioner was turned off at the start of this trial. That changes airflow and can also change temperature/humidity, so this trial should be retained but flagged as a changed-environment run.

## Interpretation

The trial shows a large response relative to short-term baseline noise, but the BME688 is cross-sensitive and humidity changed during exposure. This run is evidence of repeatable sensor response, not proof that the signal is orange-specific.

## Next use

Keep this trial as one independent unit. For machine-learning evaluation, split by whole trial rather than randomly splitting individual time samples.
