# Orange Peel Trial 004

## Purpose

Independent orange-peel response trial for the ESP32-S3 + BME688 electronic-nose prototype.

## Hardware and logger

- ESP32-S3-N16R8
- BME688 breakout at I2C address `0x77`
- SDA: GPIO 8
- SCL: GPIO 9
- Supply: 3.3 V
- Gas heater: 320 C for 150 ms
- Serial baud: 115200

## Event timing

- Baseline: `< 100,000 ms`
- Orange-peel exposure: `100,000–210,000 ms`
- Recovery: `> 210,000 ms`

The event boundaries come from the experimenter's manual record.

## Files

- Raw sensor data: `data/raw/orange_004.csv`
- Labeled data: `data/processed/orange_004_labeled.csv`
- Quantitative summary: `data/processed/orange_004_summary.csv`

## Quantitative results

- Samples stored: **217**
- Stable/available baseline gas resistance: **344.0 kOhm**
- Baseline gas CV: **0.362%**
- Minimum exposure gas resistance: **121.0 kOhm** at **133.2 s**
- Maximum decrease from baseline: **64.8%**
- Baseline humidity: **44.71% RH**
- Peak exposure humidity: **57.83% RH**
- Humidity increase: **13.12 percentage points**
- Final-60-s recovery gas mean: **323.8 kOhm**
- Approximate recovery fraction: **91.0%**

## Data-quality note

The copied serial output contained older measurements before an ESP32 reboot. Only rows after the final CSV header were kept. The user later corrected the exposure interval to 100,000–210,000 ms.

## Interpretation

The trial shows a large response relative to short-term baseline noise, but the BME688 is cross-sensitive and humidity changed during exposure. This run is evidence of repeatable sensor response, not proof that the signal is orange-specific.

## Next use

Keep this trial as one independent unit. For machine-learning evaluation, split by whole trial rather than randomly splitting individual time samples.
