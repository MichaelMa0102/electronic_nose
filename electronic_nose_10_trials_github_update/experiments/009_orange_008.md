# Orange Peel Trial 008

## Purpose

Independent orange-peel response trial for the ESP32-S3 + BME688 electronic-nose prototype.

## Hardware and logger

- ESP32-S3-N16R8
- BME688 breakout at I2C address `0x77`
- SDA: GPIO 8
- SCL: GPIO 9
- Supply: 3.3 V
- Gas heater: 320 C for 150 ms
- Serial baud: 115200

## Event timing

- Baseline: `< 100,000 ms`
- Orange-peel exposure: `100,000–210,000 ms`
- Recovery: `> 210,000 ms`

The event boundaries come from the experimenter's manual record.

## Files

- Raw sensor data: `data/raw/orange_008.csv`
- Labeled data: `data/processed/orange_008_labeled.csv`
- Quantitative summary: `data/processed/orange_008_summary.csv`

## Quantitative results

- Samples stored: **221**
- Stable/available baseline gas resistance: **336.6 kOhm**
- Baseline gas CV: **0.447%**
- Minimum exposure gas resistance: **133.8 kOhm** at **119.5 s**
- Maximum decrease from baseline: **60.2%**
- Baseline humidity: **44.53% RH**
- Peak exposure humidity: **75.27% RH**
- Humidity increase: **30.74 percentage points**
- Final-60-s recovery gas mean: **306.4 kOhm**
- Approximate recovery fraction: **85.1%**

## Data-quality note

The user corrected the exposure interval to 100,000–210,000 ms. This trial has a particularly large humidity excursion, so gas response cannot be interpreted as odor chemistry alone.

## Interpretation

The trial shows a large response relative to short-term baseline noise, but the BME688 is cross-sensitive and humidity changed during exposure. This run is evidence of repeatable sensor response, not proof that the signal is orange-specific.

## Next use

Keep this trial as one independent unit. For machine-learning evaluation, split by whole trial rather than randomly splitting individual time samples.
