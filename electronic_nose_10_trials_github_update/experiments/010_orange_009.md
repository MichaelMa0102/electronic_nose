# Orange Peel Trial 009

## Purpose

Independent orange-peel response trial for the ESP32-S3 + BME688 electronic-nose prototype.

## Hardware and logger

- ESP32-S3-N16R8
- BME688 breakout at I2C address `0x77`
- SDA: GPIO 8
- SCL: GPIO 9
- Supply: 3.3 V
- Gas heater: 320 C for 150 ms
- Serial baud: 115200

## Event timing

- Baseline: `< 110,000 ms`
- Orange-peel exposure: `110,000–210,000 ms`
- Recovery: `> 210,000 ms`

The event boundaries come from the experimenter's manual record.

## Files

- Raw sensor data: `data/raw/orange_009.csv`
- Labeled data: `data/processed/orange_009_labeled.csv`
- Quantitative summary: `data/processed/orange_009_summary.csv`

## Quantitative results

- Samples stored: **220**
- Stable/available baseline gas resistance: **305.1 kOhm**
- Baseline gas CV: **0.443%**
- Minimum exposure gas resistance: **158.9 kOhm** at **140.0 s**
- Maximum decrease from baseline: **47.9%**
- Baseline humidity: **51.11% RH**
- Peak exposure humidity: **66.74% RH**
- Humidity increase: **15.63 percentage points**
- Final-60-s recovery gas mean: **289.8 kOhm**
- Approximate recovery fraction: **89.5%**

## Data-quality note

One residual measurement from the previous run appeared before the ESP32 reboot banner and was discarded. Only the post-reboot run is stored.

## Interpretation

The trial shows a large response relative to short-term baseline noise, but the BME688 is cross-sensitive and humidity changed during exposure. This run is evidence of repeatable sensor response, not proof that the signal is orange-specific.

## Next use

Keep this trial as one independent unit. For machine-learning evaluation, split by whole trial rather than randomly splitting individual time samples.
